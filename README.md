# Master CV Portfolio

Formal mentor-facing portfolio for Nguyen Quang Minh Tri, prepared for 2027 postgraduate and scholarship discussions.

## Stack
- React
- Vite
- CSS animations and IntersectionObserver (no animation framework)

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

The portfolio content is based on the applicant information, professional experience, project notes, and bachelor-thesis material maintained in `My_future`.
